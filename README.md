## Architectural & Design Philosophy

The website is crafted around an editorial philosophy of **Warm Brutalism** and **Italian Rationalism**, treating digital space as an extension of architectural practice:

- **Rationalist Layout & Spatial Balance**: Asymmetric editorial grids, calibrated whitespace, horizontal divider rules, and generous margins that allow photographic works to breathe.
- **Materiality & Color Palette**: Grounded in natural architectural materials — lime plaster white (`#F8F7F4`), volcanic anthracite (`#292925`), soft travertine ivory (`#F1EFE9`), pale mortar rules (`#E2DBD0`), and muted Roman travertine sage (`#8A8D76`).
- **Typographic Hierarchy**:
  - **Manrope**: Humanist geometric grotesque for editorial headings and long-form narrative.
  - **IBM Plex Mono**: Technical monospaced typography for project metadata, spatial metrics, architectural labels, and coordinate indexes (`01 — PROGETTI`).
- **Architectural Passe-Partout Framing**: Bespoke photographic presentation frames with symmetric rounded corners (`rounded-[14px]` to `rounded-[18px]`) and soft neutral backgrounds (`#F1EFE9` / `#E2DBD0`).
- **Choreographed Motion Engine**:
  - High-precision GSAP timeline animations for hero sequences and smooth viewport-triggered image reveals.
  - Custom SplitText typography animations that elevate editorial headlines without jarring layout shifts.
  - Complete zero-flash first-paint architecture (eliminates Flash of Unstyled Content/FOUC).
  - Full support for `prefers-reduced-motion: reduce` and zero-JavaScript graceful degradation.

## Technology Stack

| Layer | Technology | Details |
| :--- | :--- | :--- |
| **Framework** | [Astro](https://astro.build/) `v7.x` | Static Site Generation (SSG), zero runtime JS overhead by default, automatic sitemap generation. |
| **Styles** | [Tailwind CSS](https://tailwindcss.com/) `v4.x` | Modern engine with `@tailwindcss/vite`, CSS cascade layers, and responsive typography variables. |
| **Typography** | `@fontsource` | Self-hosted `manrope` and `ibm-plex-mono` (GDPR-compliant, no third-party Google font trackers). |
| **Motion** | [GSAP](https://greensock.com/gsap/) `v3.15` | GPU-accelerated transforms, clip-path mask reveals, and smooth scroll animations. |
| **Image Pipeline**| [Sharp](https://sharp.pixelplumbing.com/) | Lossless WebP conversion, pre-calculated responsive dimensions, and progressive decoding. |
| **SEO & Schema** | OpenGraph + JSON-LD | Structured schema for `ArchitecturalFirm` & `LocalBusiness`, canonical tags, and dynamic sitemap. |
| **QA Automation**| [Playwright](https://playwright.dev/) | End-to-end multi-viewport test suite, accessibility validation, and motion frame regression testing. |
| **Deployment** | [Netlify](https://www.netlify.com/) | Edge CDN deployment, immutable asset caching, and hardened security headers via `netlify.toml`. |

## Getting Started

### Prerequisites

- **Node.js**: `v20.x` or `v22.x` (LTS recommended)
- **npm**: `v10.x` or higher

### 1. Clone the repository

```bash
git clone https://github.com/appuntostudio/appuntostudio.git
cd AppuntoStudio
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start development server

```bash
npm run dev
```

The local development server will start at `http://localhost:4321`.

### 4. Code & Type Checking

To validate all Astro templates, TypeScript types, and imports:

```bash
npm run check
```

### 5. Build for Production

Compile optimized static HTML, CSS, JavaScript, and sitemap into the `dist/` directory:

```bash
npm run build
```

To preview the built production bundle locally:

```bash
npm run preview
```

## Automated QA & Test Suites

The project includes two end-to-end Playwright verification suites:

### Full QA & Responsive Multi-Viewport Suite

Validates all 11 site routes, checks HTTP 200 response codes, ensures 0 console errors, verifies 0 broken assets, tests interactive components (mobile menu, Lightbox modal, keyboard Escape navigation), validates WCAG 2.2 AA accessibility (skip-link, single H1, image alt attributes), and verifies 0 horizontal overflow across 9 viewports:

```bash
npm test
```

Tested viewports:
- `320x800` (Small Mobile)
- `360x800` (Android Standard)
- `390x844` (iPhone 12/13/14)
- `430x932` (iPhone Pro Max)
- `768x1024` (Tablet Portrait)
- `1024x768` (Tablet Landscape)
- `1280x800` (Laptop / Notebook)
- `1440x900` (Desktop Standard)
- `1920x1080` (Large Display)

### Motion Design & Zero-Flash Suite

Measures frame-by-frame stability of the hero reveal at 0ms, 180ms, 400ms, 700ms, and 1300ms, verifies warm/cold cache reload behavior, tests below-the-fold scroll triggers, multi-page history navigation, and verifies immediate fallback for `prefers-reduced-motion` and JavaScript-disabled environments:

```bash
npm run test:motion
```

## Deployment to Netlify

This project is pre-configured for continuous deployment on **Netlify** via `netlify.toml`.

### Method A: Git Continuous Deployment (Recommended)

1. Push your repository to GitHub:
   ```bash
   git remote add origin https://github.com/<your-username-or-org>/appuntostudio.git
   git branch -M main
   git push -u origin main
   ```
2. Log in to [Netlify App](https://app.netlify.com/).
3. Click **"Add new site"** > **"Import an existing project"**.
4. Authorize GitHub and select the `appuntostudio` repository.
5. Netlify will automatically detect `netlify.toml` settings:
   - **Base directory**: `.` (leave empty or default)
   - **Build command**: `npm run build`
   - **Publish directory**: `dist`
   - **Node.js Version**: `20`
6. Click **"Deploy site"**. Every commit pushed to `main` will automatically trigger a clean static build and instant global edge deployment.

### Method B: Netlify CLI Deployment

If you prefer deploying directly from your terminal:

```bash
# 1. Install Netlify CLI globally or run with npx
npx netlify login

# 2. Link your local project
npx netlify init

# 3. Build and deploy to production
npm run build
npx netlify deploy --prod --dir=dist
```

### Custom Domain & DNS Setup

To link `www.appuntostudio.it`:
1. In your Netlify dashboard, go to **Site settings** > **Domain management**.
2. Add custom domain: `www.appuntostudio.it`.
3. Configure your DNS provider:
   - **Apex / Root domain (`appuntostudio.it`)**: Set an `A` record pointing to Netlify's load balancer IP `75.2.60.5` (or Netlify DNS).
   - **Subdomain (`www.appuntostudio.it`)**: Set a `CNAME` record pointing to `<your-site-name>.netlify.app`.
4. Netlify will provision a free automated Let's Encrypt SSL/TLS certificate.

### Security Headers & Caching Strategy

Defined in `netlify.toml`:
- `X-Frame-Options: DENY`: Prevents clickjacking attacks.
- `X-Content-Type-Options: nosniff`: Enforces strict MIME typing.
- `Referrer-Policy: strict-origin-when-cross-origin`: Protects user navigation context.
- `/_astro/*`: 1-year immutable caching (`max-age=31536000, immutable`) for fingerprint-hashed assets.
- `/images/*`: 30-day edge cache with `stale-while-revalidate` for photographic portfolios.
- `/*`: Custom `404.html` redirect response.

## Accessibility & Performance Standards

- **WCAG 2.2 AA Compliant**: Proper heading order, high-contrast ratios, focus visible rings, keyboard-navigable dialogs with focus trapping.
- **Progressive Enhancement**: All content, images, and texts are fully rendered in raw HTML. The site remains 100% usable without JavaScript.
- **Privacy by Design**: Zero third-party trackers, zero advertising scripts, no invasive cookies. GDPR-ready.
